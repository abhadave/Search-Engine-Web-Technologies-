🖼️ Image Search Engine

A simple and stylish image search engine built with HTML, CSS, and JavaScript, using an external image API to fetch photos based on user input.

🚀 Features

🔍 Search images by typing any keyword

⚡ Fast API results

🎨 Modern UI with clean layout

📱 Responsive design

🖼️ Displays images in a grid format

📁 Project Structure

SEARCHENGINE/
│── index.html
│── style.css
│── script.js
│── README.md

🧩 How It Works

User enters a keyword inside the search bar

JavaScript fetches images from the API

Fetched images are displayed dynamically on the screen

🛠️ Installation & Setup

Clone or download the project

Open index.html in any browser

Make sure your API key is added inside script.js (if required by the API you use)
